# Hull

> Hull is a real-time Customer Data Platform (CDP) that unifies customer data from every source into a single User and Account profile via claim-based identity resolution, then syncs enriched, segmented data out to marketing, sales and analytics tools through Connectors. Hull is now part of MessageBird (Bird) and is closed to new customers; this profile documents its public developer surface. (method: generated from apis.yml + repo artifacts)

## APIs
- [Hull HTTP API](https://www.hull.io/docs/reference/http_api/introduction/): Flat REST API at https://{organization}.hullapp.io/api/v1 covering Users, Accounts, Events, Segments, Status and Bulk operations.
